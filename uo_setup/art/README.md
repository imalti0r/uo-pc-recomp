# Launcher artwork

- `backdrop.jpg`: Unicorn Overlord key art supplied by the user on 2026-11-14
  (downloaded from `images.alphacoders.com`), cropped to 16:9, graded and faded
  into a dark panel on the left by `tools/make_launcher_art.py`. This is the
  game's own artwork and belongs to ATLUS / Vanillaware / SEGA; it ships as the
  launcher's background for an unofficial port and is not covered by this
  repository's MIT licence.
- `wordmark.png`: lettering drawn by `tools/make_launcher_art.py` from Roboto
  Medium (Apache-2.0, `runtime/ui/fonts`), filled with a gold gradient. It names
  the game this unofficial port supports; it is not an official logo.

The launcher renders its controls and status separately. Both files are
regenerated by `python tools/make_launcher_art.py`, which needs the source key
art at `build/art_src.jpeg`.
